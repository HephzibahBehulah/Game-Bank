# Drone Racing

Six-pilot FPV-style racing across five authored circuits. Two local drivers race against four rule-driven AI pilots. Each circuit has ordered gates, crosswind, and two red hazard zones. Thrust builds speed; boost spends battery; steering yaws the drone; a gate only scores when crossed in route order. Finish three laps to win, see the full flight order, and unlock the next course.

## Run
Open the Godot 4.7 or newer project at couch-suite/project.godot. Choose Racing → Drone Racing from the hub, or run games/drone_racing.tscn.

## Controls
- Player 1 keyboard: W throttle, A/D yaw, S airbrake, Shift boost.
- Player 2 keyboard: Up throttle, Left/Right yaw, Down airbrake, Enter boost.
- Gamepad: left stick yaw, RT throttle, LT brake, RB boost, A/Cross start, Start/Options pause.
- Escape / B returns from the briefing to the hub.

Routes and pilots are fictional. Flight behavior is an arcade racing model, not guidance for operating real aircraft.
