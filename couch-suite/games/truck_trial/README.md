# Truck Trial

Drive a slow, heavy recovery truck through eight authored obstacle courses. Reach each finish without exceeding the 48-degree rollover limit. Carry momentum carefully: high-speed impacts create body roll, while braking settles the chassis. Crane Yard and Timber Recovery add an articulated lift gate or fallen-tree obstacle.

## Run

Open `couch-suite/project.godot` with Godot 4.x, select Truck Trial from the hub, choose an unlocked course, and start the stage.

## Controls

- Keyboard: W or Up to throttle, S or Down to brake, T/G to raise/lower the crane, Left/Right to select a course.
- Xbox or PlayStation pad: RT throttle, LT brake, right stick vertical crane control, D-pad course selection, A start/continue, B return, Start pause.
- On courses without crane obstacles the right stick has no effect.

## Progress

A clean finish records the stage time and unlocks the next course. Rollover ends the run; use B to retry. Progress is stored locally in `user://truck_trial_progress.json`.
