# Hovercraft Time Attack

Pilot a twin-fan hovercraft across eight authored time-attack courses. Each course changes thrust, drag, water chop, crosswind, gate lanes and buoy hazards. The craft carries momentum: steer early, counter-steer to settle, and spend a rechargeable fan boost on long straights. Hitting buoys damages hull integrity and slows the craft; hull failure ends the attempt.

## Run
Open `couch-suite/project.godot` in Godot 4.7 or newer. Choose Racing → Hovercraft Time Attack from the hub, or run `games/hovercraft_time_attack.tscn`.

## Controls
- W / Up Arrow: thrust.
- A / Left and D / Right: steer.
- S / Down / Space: brake.
- Shift: boost.
- Gamepad RT: thrust; left stick: steering; LT: brake; RB: boost; D-pad: course select; A/Cross: start; Start/Options: pause.
- Escape / B: return to course select or hub.

Aim for the amber line in every gate. Red buoys mark collision zones. Finish to earn a time, score, rating and unlock the next course. Career bests save locally.

Routes and teams are fictional. The simulation is an arcade handling model, not a real-world vessel simulator.
