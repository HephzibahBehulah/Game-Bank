# Motorcycle Hill Climb

Race a motorbike up eight individually authored mountain routes. Each stage has a defined elevation profile and traction level. Manage your speed over grades, use left or right lean to control chassis pitch, clear the marked jump at its minimum speed, and land below the loop-out limit.

## Run

Open `couch-suite/project.godot` in Godot 4.x and select Motorcycle Hill Climb from the hub.

## Controls

- Keyboard: W or Up to throttle, S or Down to brake, A/D or Left/Right to lean, Left/Right to select a stage while in the briefing.
- Xbox or PlayStation pad: RT throttle, LT brake, left stick horizontal to lean, D-pad stage selection, A start/continue, B return, Start pause.
- To retry after a crash, press B / Escape to return to stage selection and start again.

## Progress

Finishing a summit records the best time and unlocks the next stage. A crash does not unlock a stage. Career data is stored locally in `user://motorcycle_hill_progress.json`.
